# ART MANIFEST — LAST SIGNAL Director's Cut v2 (Wave 1)

Every asset below is procedurally generated by a committed, deterministic
(seeded) script under `tools/artgen/`. No engine required to regenerate.

Regenerate everything:

```
python3 tools/artgen/gen_aria_portraits.py
python3 tools/artgen/gen_erebus_presence.py
python3 tools/artgen/gen_endings.py
python3 tools/artgen/gen_keyart.py
python3 tools/artgen/gen_ui_skin.py
python3 tools/artgen/verify_assets.py        # integrity + contact sheets
```

Palette: deep-space blues/teals (`#0C2648`, `#1890A0`, `#58D6E0`) with
signal-orange accent (`#FF8C1A`). CRT-friendly contrast throughout.

## Verification

`python3 tools/artgen/verify_assets.py` opens every PNG (size/mode/alpha/
histogram checks), fails non-zero on any problem, and writes contact sheets
to `tools/artgen/sheets/` for human review.
